# Penn Dining — Search & Filter Prototype

Interactive iPhone prototype for searching and filtering Penn dining hall menus, built with React, Vite and Tailwind CSS.

## Run it

```bash
npx pnpm install
npx pnpm dev
```

Then open the `http://localhost:…` link it prints.

## What's in it

- Home screen with dining balance, search bar and dining halls
- Search with recent searches, recommended chips and venue tabs
- Filter sheet (meal, show-only, exclude) with drag-to-dismiss
- Item detail sheet with nutrition info and ingredients
- Collapsible dining halls and stations

Menu data is hard-coded for the prototype.
